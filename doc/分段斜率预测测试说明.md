# 分段斜率预测测试说明

测试用来锁定网络的梯度、窗口顺序和预测表的形状，避免以后改训练循环时把均方误差的导数算反，或把更早的 K 线排到窗口后面。用例在 `tests/test_forecast.py`，不依赖掘金，也不改 `main.py`。

## 怎么运行

在项目根目录 `SmartStock` 下：

```text
python -m pytest tests/test_forecast.py -q
```

numpy、pandas 和 pytest 沿用项目里已有的环境，不需要再装深度学习框架。样例 CSV 在 `data/` 时，最后一行是 `12 passed`。样例不在时，`test_sample_csv_smoke` 会跳过，最后一行是 `11 passed, 1 skipped`。

只跑梯度对照：

```text
python -m pytest tests/test_forecast.py::test_backward_matches_finite_difference -q
```

样例文件 `data/SHSE_600016.csv` 被 git 忽略。文件不在时，其余手造用例仍会执行。

## 测试怎么组织

分三层：

1. 数值对照。用有限差分核对某一处权重和偏置的梯度。期望的差分直接从损失算出来，不从反向传播函数反推。
2. 拟合与调用约定。一条由输入列线性组成的斜率，训练后损失要降到初始损失的十分之一以内，预测和这条斜率的绝对差不超过 0.1。另外锁定窗口顺序、时间排序、空值填补、存盘读回、缺列和命令行。
3. 样例冒烟。对民生银行这张日线训练 20 轮，确认除 `segment` 外的每一列都进入特征，预测行数等于总行数减去窗口再加 1，并且预测值都是有限数。

失败时先看用例名。有限差分失败，说明均方误差或 ReLU 的反向传播变了；拟合失败，说明学习率、标准化或批次打乱的口径变了；冒烟失败，说明特征列被丢掉，或窗口把开头几根也输出了。

## 用例对照

| 用例 | 锁定的结果 |
|------|------------|
| test_sliding_window_puts_older_bars_first | 窗口按从早到晚拉直，更早的 K 线在向量前部 |
| test_backward_matches_finite_difference | 第一层一个权重、输出层一个偏置的梯度与中心差分一致 |
| test_training_reduces_loss_on_a_known_slope | 80 行线性斜率上，最终训练损失小于初始损失的十分之一，预测绝对差不超过 0.1 |
| test_predict_follows_time_order_and_does_not_mutate_input | 输入表不改。窗口为 3 时输出少 2 行，第一行对应该段时间上的第 3 根 K 线。特征列不含 `segment` |
| test_missing_feature_is_filled_with_training_median | 特征空值用该列有限值的中位数填上，预测仍是有限数 |
| test_save_load_round_trip_keeps_predictions | npz 读回后，同一张表的预测与保存前一致 |
| test_missing_segment_short_frame_and_bad_arguments_raise | 缺 `segment`、斜率含空值、行数少于窗口、窗口为 0、学习率为 0 都会报错 |
| test_predict_requires_training_columns | 预测时缺训练用过的列会报错 |
| test_without_eob_outputs_row_index | 没有 `eob` 时输出 `row` 和 `segment`，行号从窗口末根开始 |
| test_cli_train_and_predict | `python -m forecast train` 与 `predict` 的标准输出是写出的路径，预测表有 `eob` 和 `segment` |
| test_write_helpers_use_default_names | 默认文件名是 `原名_segment_model.npz` 和 `原名_segment_pred.csv` |
| test_sample_csv_smoke | `data/SHSE_600016.csv` 的全部非 `segment` 列进入网络；20 轮后有验证损失；预测行数是 250 减去窗口再加 1 |

## 样例上再看什么

冒烟通过只说明这张真实日线能训练完、预测值没有变成空或无穷。打开预测 CSV 后可以再看两处：

1. 开头是否少了 `window - 1` 根，时间是否从早到晚。
2. 预测斜率是否大部分落在样例 `segment` 的范围内。这张表的斜率大约在 -0.09 到 0.11 之间，均值接近 0。

对不上时，先用测试里那条 `0.8 * signal - 0.2 * close` 的手造斜率看网络还能不能把损失降下去。手造数据对得上、长表对不上，优先检查窗口、验证集切分和这张表的复权，而不是先改隐藏层宽度。
