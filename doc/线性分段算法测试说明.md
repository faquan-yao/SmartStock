# 线性分段算法测试说明

测试用来锁定自底向上分段的切点和斜率，避免以后改代码时把误差口径或分段点的取值改歪。用例在 `tests/test_segment.py`，不依赖掘金，也不改 `main.py`。

## 怎么运行

在项目根目录 `SmartStock` 下：

```text
python -m pip install pytest
python -m pytest tests/test_segment.py -q
```

当前环境已安装 pytest 时，第二条就能跑。全部通过时，最后一行是类似 `15 passed` 的统计，退出码为 0。

`python -m pytest tests -q` 会连同技术指标用例一起跑。

只跑某一个用例：

```text
python -m pytest tests/test_segment.py::test_peak_breakpoint_uses_the_following_slope -q
```

样例文件 `data/SHSE_600031.csv` 被 git 忽略。文件不在时，`test_sample_csv_smoke` 会跳过，其余手算用例仍会执行。

## 测试怎么组织

分三层：

1. 手算短序列。用几根自己算得出的收盘价，和函数输出的斜率逐项比较。期望值写在测试里，不从被测函数反推。
2. 调用约定。默认阈值是 0.03；结果按 `eob` 排序且不改调用方的表；缺列、非数字、零价格和非法阈值会报错；命令行能写出 CSV。
3. 样例冒烟。对三一重工这张日线做分段，检查每段误差不超过默认阈值，相邻段不能再合并，并且 `segment` 等于对应直线的斜率。

失败时先看用例名。手算用例失败，说明切点或斜率口径变了；冒烟失败，说明阈值、排序或整段合并的停止条件变了。

## 手算用例对照

下面的斜率都是（段末收盘价 − 段初收盘价）/ 间隔的 K 线数。分段点取后一段的斜率。

| 用例 | 锁定的结果 |
|------|------------|
| test_default_threshold_is_three_percent | 默认最大相对误差为 0.03 |
| test_straight_line_slope_is_constant | `[1,2,3,4,5]` 是一条斜率 1 的直线 |
| test_peak_breakpoint_uses_the_following_slope | `[1,2,3,4,3,2,1]` 在第 4 根转折，斜率先 1 后 -1，转折点为 -1 |
| test_large_threshold_merges_into_one_flat_slope | 同一序列在阈值 0.75 时合成一段，斜率全为 0 |
| test_zero_threshold_keeps_only_exact_lines | `[1,2,3,2.5]` 在阈值 0 时分为斜率 1 和 -0.5 |
| test_two_point_segment_before_a_turn | `[1,3,2]` 在阈值 0 时不能合并，斜率为 2、-1、-1 |
| test_single_bar_slope_is_empty | 只有一根 K 线时斜率为空 |
| test_empty_frame_keeps_columns | 空表仍有 `eob`、`segment` 两列 |
| test_rows_follow_eob_without_mutating_input | 按 eob 排序，输入表保持原样；排好后的 `[1,2,3]` 斜率为 1 |
| test_missing_or_non_numeric_close_raises | 缺收盘价、收盘价不是数字时抛出 ValueError |
| test_negative_or_bool_threshold_raises | 负阈值和布尔值都会报错 |
| test_zero_close_raises | 收盘价为 0 时报错 |
| test_write_segments_round_trip | 默认输出名为 `原名_segments.csv` |
| test_cli_writes_csv | `python -m segment 输入.csv -o 输出.csv --max-error 0.03` 能写出斜率 |
| test_sample_csv_smoke | 用 `data/SHSE_600031.csv` 做下面的冒烟 |

比较使用 `pytest.approx`，允许约 `1e-6` 的相对误差。单根 K 线的斜率是空值，测试会确认它不是 0。

## 样例 CSV 冒烟检查什么

`test_sample_csv_smoke` 对 `SHSE_600031.csv` 做这些检查：

- 输出行数与输入相同，`eob` 与输入一致且升序，输入表不被改写。
- 列只有 `eob` 和 `segment`，斜率都是有限数。
- 斜率发生变化的位置是分段点。每个点的斜率等于从本段起点到本段终点的收盘价变化除以间隔根数。
- 同一条直线在写入范围内斜率相同。分段点落在后一段的范围内。
- 每一段的最大相对误差不超过默认阈值 0.03。
- 相邻两段再合并的误差大于 0.03。

这条测试通过，只说明默认阈值在这张真实日线上满足停止条件，不能代替手算用例。

## 和手算对一下

1. 先看 `test_peak_breakpoint_uses_the_following_slope`。序列 `1,2,3,4,3,2,1` 的前四点连线斜率是 `(4-1)/3 = 1`，后四点是 `(1-4)/3 = -1`。第 4 根是共用端点，`segment` 必须是 -1，不能仍是 1。
2. 把阈值提高到 0.75 后，整段相对误差刚好等于 0.75，应当合成一条从 1 回到 1 的水平线，斜率全为 0。
3. 真实日线上的段数会随 `max_error` 变化。段数变了而手算用例仍通过，说明变的是阈值，不是切分规则。
