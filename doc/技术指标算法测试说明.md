# 技术指标算法测试说明

测试用来锁定公式，避免以后改代码时把通达信口径改歪。用例在 `tests/test_indicators.py`，不依赖掘金，也不改 `main.py`。

## 怎么运行

在项目根目录 `SmartStock` 下：

```text
python -m pip install pytest
python -m pytest tests -q
```

当前环境已安装 pytest 时，第二条就能跑。全部通过时，最后一行是类似 `26 passed` 的统计，退出码为 0。

只跑某一个用例：

```text
python -m pytest tests/test_indicators.py::test_macd_histogram_is_twice_the_difference -q
```

样例文件 `data/history_SHSE600000.csv` 被 git 忽略。文件不在时，`test_sample_history_smoke` 会跳过，其余手算用例仍会执行。

## 测试怎么组织

分三层：

1. 手算短序列。每个指标用几根自己算得出的 K 线，和函数输出逐项比较。期望值写在测试里，不从被测函数反推。
2. 整表约定。`compute_all` 必须保留原始列，并按固定顺序追加 66 个指标列；按 `eob` 排序，且不改调用方的表。
3. 样例冒烟。对浦发银行这张日线算完全部指标，检查行数、空值位置、取值范围，以及几条恒等关系。

失败时先看用例名。手算用例失败，说明公式变了；冒烟失败，说明整表拼接、排序或默认参数变了。

## 样例 CSV 冒烟检查什么

`test_sample_history_smoke` 对浦发银行日线做这些检查：

- 输出行数与输入相同，`eob` 升序。
- 指标列名、顺序与上表一致。
- `ma5` 等于收盘价的 5 日滚动均值。
- 默认参数下 `boll_mid`、`env_mid` 等于 `ma20`。
- `macd_hist = 2 × (macd_dif - macd_dea)`。
- `kdj_j = 3 × kdj_k - 2 × kdj_d`。
- RSI14、MFI 落在 0 到 100，WR6 落在 -100 到 0，SAR 方向只有 1 和 -1。
- 第一根枢轴点为空。
- 不少于 250 根时，`ma250` 的前 249 根为空，第 250 根有值。
- 全部指标列没有无穷大。

这条测试通过，只说明默认参数在这张真实日线上没有算炸，不能代替手算用例。

## 和通达信对一下

1. 用同一只股票、同一段前复权日线，参数与使用说明中的默认值相同。
2. 先对最后一根的 MA20、RSI14、MACD 柱。这三项最容易看出公式是否一致。
3. MACD 柱请看 `macd_hist`。通达信图上的柱状值是 DIF 与 DEA 之差的 2 倍。
4. WR 请先把软件上的正数取负，再和 `wr6`、`wr10` 比。
5. BOLL 上下轨若整体略有差别，先确认软件标准差是除以 N 还是除以 N-1。本实现除以 N。
6. SAR 的前几根允许和软件不同。本实现用前两根中价定方向，并用前两根高低价限制 SAR，不另设 10 日初始窗口。
7. VWAP 不要和 `amount / volume` 比。复权价与未复权成交额不是同一个价格尺度。

对不上时，用测试里的短序列在软件公式编辑器里算同一组数。短序列对上、长序列对不上，优先检查复权方式和缺日，而不是先改公式。
