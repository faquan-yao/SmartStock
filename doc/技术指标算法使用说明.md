# 技术指标算法使用说明

本模块按国内行情软件（通达信）的常用公式，计算《股票常用技术指标》里列出的全部指标。结果只描述价格和成交量的历史统计特征，不构成投资建议。

计算入口在 `indicators` 包。策略脚本 `main.py` 不参与计算，也不需要先登录掘金。

## 输入数据

读入一张日线表，至少包含这些列：

| 列名 | 含义 |
|------|------|
| open | 开盘价 |
| high | 最高价 |
| low | 最低价 |
| close | 收盘价 |
| volume | 成交量 |

`data/history_SHSE600000.csv` 就是这种表，另外还有 `symbol`、`amount`、`eob`。这三列会原样保留。

- 有 `eob` 时，结果按时间从早到晚排列。
- 没有 `eob` 时，按表中现有行序计算，调用方需要自己保证从早到晚。
- 周期不够的位置是空值，不会用 0 填充。
- 输出保留完整小数，不按行情软件的显示位数四舍五入。

成交额 `amount` 不参与计算。样例里的价格是前复权价，成交额仍是未复权金额，两者相除得到的价格和收盘价不是同一个口径。VWAP 改为用复权后的典型价加权。

## 在代码里计算

在项目根目录 `SmartStock` 下执行。

一次算完全部指标：

```python
from indicators import compute_all, load_history

history = load_history("data/history_SHSE600000.csv")
result = compute_all(history)
result.to_csv("data/history_SHSE600000_indicators.csv", index=False)
```

`result` 前面是原始列，后面是 66 个指标列。原始表不会被改写。

只算某一个指标时，调用同名函数。周期参数可以改，不传就用下面的默认值。

```python
from indicators import macd, rsi

macd_frame = macd(history)                  # 12, 26, 9
rsi_frame = rsi(history, periods=(6, 14))   # 只要 RSI6 和 RSI14
```

各函数返回的都是新的 DataFrame，索引为按时间排好后的 `0 .. n-1`。

## 命令行

```text
python -m indicators data/history_SHSE600000.csv -o data/history_SHSE600000_indicators.csv
```

省略 `-o` 时，输出文件名为原文件名加上 `_indicators`，例如 `history_SHSE600000_indicators.csv`，和输入放在同一目录。已有同名文件会被覆盖。

## 公式

下列写法里，`REF(X, N)` 是 N 根之前的值，`MA` 是简单算术平均，有效值从第 N 根开始。

### 平滑

通达信 EMA，第一条有效值等于自己：

```text
EMA = (2 × 当前值 + (N - 1) × 上一期 EMA) / (N + 1)
```

通达信 SMA(X, N, 1)，RSI 和 KDJ 使用。第一条有效值等于自己，中间的空值跳过、不重置：

```text
SMA = (当前值 + (N - 1) × 上一期 SMA) / N
```

### 趋势

```text
MA(N) = N 日收盘价之和 / N
DIF = EMA(收盘价, 12) - EMA(收盘价, 26)
DEA = EMA(DIF, 9)
MACD 柱 macd_hist = 2 × (DIF - DEA)

BOLL 中轨 = MA(收盘价, 20)
标准差 = 总体标准差，除以 20，不是样本标准差
上轨 = 中轨 + 2 × 标准差
下轨 = 中轨 - 2 × 标准差
```

SAR：

- 用前两根 K 线的（最高价 + 最低价）比较方向。第二根中价更高则为多头。
- 多头的第一点放在第一根最低价，空头放在第一根最高价。`sar_trend` 为 1 或 -1。
- 下一点 = 上一点 + 加速因子 ×（极值 - 上一点）。
- 多头时，SAR 不得高于前两根 K 线的最低价；空头时不得低于前两根最高价。
- 最低价跌破 SAR 则转为空头，SAR 跳到此前最高价；最高价升破 SAR 则相反。
- 创新高或新低后，加速因子从下一根才增加 0.02，最高 0.2。反向后回到 0.02。
- 只有一根 K 线时，SAR 为空。

### 动量

```text
涨幅 = max(收盘价 - 昨收, 0)
RSI = SMA(涨幅, N, 1) / SMA(|收盘价 - 昨收|, N, 1) × 100

RSV = (收盘价 - N 日最低价) / (N 日最高价 - N 日最低价) × 100
K = SMA(RSV, 3, 1)
D = SMA(K, 3, 1)
J = 3K - 2D

典型价 TYP = (最高价 + 最低价 + 收盘价) / 3
CCI = (TYP - MA(TYP, 14)) / (0.015 × AVEDEV(TYP, 14))

WR = (N 日最高价 - 收盘价) / (N 日最高价 - N 日最低价) × (-100)

ROC = (收盘价 - REF(收盘价, 12)) / REF(收盘价, 12) × 100
MOM = 收盘价 - REF(收盘价, 12)
```

WR 按文档使用负值：接近 0 偏超买，接近 -100 偏超卖。通达信画面上常把同一指标画成 0 到 100 的正数，那个正数等于这里的 WR 取绝对值。

最高价等于最低价时，RSV 和 WR 为空，K、D、J 在该根不更新平滑状态。

### 成交量

```text
vol_maN = MA(成交量, N)

OBV：收盘上涨则加成交量，下跌则减，平盘不变。第一根记 0。

VWAP = 累计(TYP × 成交量) / 累计成交量

正资金流：TYP 上升时的 TYP × 成交量，否则为 0
负资金流：TYP 下降时的 TYP × 成交量，否则为 0
MFI = 100 - 100 / (1 + N 日正资金流之和 / N 日负资金流之和)
```

负资金流之和为 0、正资金流之和大于 0 时，MFI 为 100。两边都是 0 时为空。

### 波动与通道

```text
TR = max(最高价 - 最低价, |最高价 - 昨收|, |最低价 - 昨收|)
第一根没有昨收，TR = 最高价 - 最低价
ATR = MA(TR, 14)

唐奇安上轨 = N 日最高价（含当日）
唐奇安下轨 = N 日最低价（含当日）
唐奇安中轨 = (上轨 + 下轨) / 2

轨道中轨 = MA(收盘价, 20)
轨道上轨 = 中轨 × 1.06
轨道下轨 = 中轨 × 0.94
```

`envelope` 的 `width=0.06` 表示 6 个点的比例，不是整数 6。

### 其他

```text
BIAS = (收盘价 - MA(收盘价, N)) / MA(收盘价, N) × 100

PSY = N 日内收盘价高于昨收的天数 / N × 100
第一根没有昨收，计为没有上涨。

HD = 最高价 - 昨最高价
LD = 昨最低价 - 最低价
+DM = HD > 0 且 HD > LD 时取 HD，否则 0
-DM = LD > 0 且 LD > HD 时取 LD，否则 0
PDI = N 日 +DM 之和 / N 日 TR 之和 × 100
MDI = N 日 -DM 之和 / N 日 TR 之和 × 100
DX = |PDI - MDI| / (PDI + MDI) × 100
ADX = MA(DX, 6)
```

斐波那契使用含当日的最近 60 根。窗口内最高价、最低价多次出现时，取最早那根。

- 最低价不晚于最高价：视为向上波段，`fib_trend = 1`。`fib_0` 在高点，`fib_1000` 在低点，`fib_1272`、`fib_1618`、`fib_2618` 在高点之上。
- 最高价更早：视为向下波段，`fib_trend = -1`。`fib_0` 在低点，`fib_1000` 在高点，扩展位在低点之下。

回调比例是 0、0.236、0.382、0.5、0.618、0.786、1，对应列 `fib_0`、`fib_236`、`fib_382`、`fib_500`、`fib_618`、`fib_786`、`fib_1000`。

枢轴点只用前一根的最高价 H、最低价 L、收盘价 C，当日价格不参与：

```text
PP = (H + L + C) / 3
R1 = 2 × PP - L
R2 = PP + (H - L)
R3 = H + 2 × (PP - L)
S1 = 2 × PP - H
S2 = PP - (H - L)
S3 = L - 2 × (H - PP)
```

第一根没有前一根，枢轴点为空。

## 对照行情软件时

本实现锁住的是通达信这几条规则：

- MACD 柱是 `2 × (DIF - DEA)`。
- RSI、KDJ 用 SMA(X, N, 1)，第一条等于第一个有效值，不预置 50。
- BOLL 的标准差除以 N。
- ATR 是 TR 的算术平均，不是 Wilder 的递推平滑。
- DMI 的 +DI、-DI 用 N 日求和，ADX 再做 M 日简单平均。
- WR 输出负值。

软件屏幕上的小数位数、SAR 最初几根的起算窗口，都可能和这里的完整精度有可见差别。对照时先对齐公式和参数，再比数值。EMA 和 MACD 从第一根就有值，因为首值直接取价格本身，不会先空出 26 根。

## 边界

- 缺 `open`、`high`、`low`、`close`、`volume` 任一列，直接报错。
- 价格或成交量里有无法转成数字的内容，直接报错。
- 除零、最高价等于最低价，对应结果为空，不产生无穷大。
- 周期必须是大于等于 1 的整数。
- 和指标重名的输入列会被计算结果盖掉。
