# 线性分段算法使用说明

本模块把一条收盘价序列分成若干段直线，并给出每根 K 线所在直线的斜率。结果只描述价格路径的折线近似，不构成投资建议。

计算入口在 `segment` 包。策略脚本 `main.py` 不参与计算，也不需要先登录掘金。

## 输入数据

读入一张日线表，至少包含这两列：

| 列名 | 含义 |
|------|------|
| eob | K 线结束时间 |
| close | 收盘价 |

表头和前三行可以是这样。数字只说明格式，其余列可以继续往后排：

```csv
eob,open,high,low,close,volume
2024-01-02,10.20,10.35,10.05,10.28,1200000
2024-01-03,10.28,10.40,10.15,10.36,980000
2024-01-04,10.36,10.36,10.10,10.18,1100000
```

分段只使用 `eob` 和 `close`。开高低、成交量和已经算好的技术指标不参与计算，也不出现在结果里。

- 有 `eob` 时，结果按时间从早到晚排列。
- 输出保留完整小数，不按行情软件的显示位数四舍五入。
- 原始表不会被改写。

## 在代码里计算

在项目根目录 `SmartStock` 下执行。

```python
from segment import linear_segment, load_history

history = load_history("history.csv")
result = linear_segment(history)                 # 默认最大相对误差 0.03
result = linear_segment(history, max_error=0.08) # 放宽到 8%，段更长
```

`result` 只有两列：`eob` 和 `segment`。

## 命令行

```text
python -m segment history.csv -o history_segments.csv
python -m segment history.csv --max-error 0.08
```

省略 `-o` 时，输出文件名为原文件名加上 `_segments`，例如 `history_segments.csv`，和输入放在同一目录。已有同名文件会被覆盖。

## 输出列

| 列名 | 含义 |
|------|------|
| eob | 输入中的结束时间，按从早到晚排列 |
| segment | 该根 K 线所在直线的斜率 |

结果前三行可以是这样：

```csv
eob,segment
2024-01-02,0.08
2024-01-03,-0.09
2024-01-04,-0.09
```

上面三行只说明列的样子，不是对上一节那三根 K 线的计算结果。斜率的单位是每一根 K 线的价格变化：

```text
斜率 = (段末收盘价 - 段初收盘价) / (段末序号 - 段初序号)
```

序号是按 `eob` 排好之后的位置，第一根为 0，一根 K 线占一个单位。同一条直线上的 `segment` 完全相同。两段直线共用的那根 K 线是分段点，这里写入后面一条直线的斜率。最后一根 K 线没有更后面的直线，写入它所在那段的斜率。只有一根 K 线时无法连成直线，`segment` 为空。

上升直线的斜率为正，下降直线为负，两端收盘价相同则为 0。

## 算法依据

离线分段使用 Keogh、Chu、Hart、Pazzani 在时间序列分段综述里比较过的自底向上算法（Bottom-Up）。他们比较了滑动窗口、自顶向下和自底向上：整段历史都已经在手时，自底向上每次都在当前全部相邻段里挑选合并代价最小的一对，分段质量优于另外两种贪心。参见 Eamonn Keogh, Selina Chu, David Hart, Michael Pazzani, *Segmenting Time Series: A Survey and Novel Approach*, 收录于 *Data Mining in Time Series Databases*（World Scientific, 2004）。

直线用两端点连线，也就是分段线性插值，不用最小二乘回归。两个端点唯一决定斜率，段内各点因此可以共用这一个斜率。

误差用最大相对偏离，使不同价格水平的股票可以共用同一个阈值：

```text
预测价(i) = 段初收盘价 + (段末收盘价 - 段初收盘价) × (i - 段初序号) / (段末序号 - 段初序号)
误差 = max |收盘价(i) - 预测价(i)| / |收盘价(i)|
```

`i` 只取段内、不含两端的序号。两端落在直线上，误差为 0。`max_error` 默认 `0.03`，表示段内任意收盘价偏离直线都不超过该收盘价的 3%。

步骤：

1. 把相邻两根 K 线各自连成一段。此时每段只有两个端点，误差为 0。
2. 计算每一对相邻段合并之后的误差。
3. 合并误差最小的那一对。误差相同则合并更靠左的一对。
4. 重算与新段相邻的合并误差，回到第 3 步。
5. 当最小的合并误差已经大于 `max_error`，或者整条序列已经只剩一段时停止。

因此每一段自己的误差不超过阈值，而任意保留下来的相邻两段若再合并就会超过阈值。

## 边界

- 缺 `eob` 或 `close`，直接报错。
- 收盘价里有无法转成数字的内容、空值或非有限数值，直接报错。
- 收盘价为 0 时无法做相对误差，直接报错。
- `max_error` 必须是大于等于 0 的有限实数。布尔值不算。
- 阈值等于某次合并误差时，这次合并仍然执行。
- 只有一根 K 线时，`segment` 为空，不填 0。0 表示水平直线。
