# 指标图形绘制测试说明

测试用来锁定折线端点、副图内容和输出文件，避免以后改配色或面板时把指标画丢、把分段斜率当成价格。用例在 `tests/test_charts.py`。绘图使用 matplotlib 的 Agg 后端，不打开窗口。

## 怎么运行

在项目根目录 `SmartStock` 下：

```text
python -m pip install matplotlib
python -m pytest tests/test_charts.py -q
```

matplotlib 已经列在 `requirements.txt`。样例 CSV 在 `data/` 时，最后一行是 `13 passed`。样例不在时，`test_sample_csv_smoke` 会跳过，最后一行是 `12 passed, 1 skipped`。

只跑折线端点：

```text
python -m pytest tests/test_charts.py::test_segment_vertices_follow_shared_endpoint_rule -q
```

## 用例对照

| 用例 | 锁定的结果 |
|------|------------|
| test_segment_vertices_follow_shared_endpoint_rule | 斜率 `[1,1,1,-1,-1,-1,-1]` 的折线端点是序号 0、3、6，端点之间的斜率等于分段值 |
| test_price_level_breaks_when_fib_direction_flips | 方向切换，或价位相对收盘价跳变超过 8% 时，该点断开 |
| test_straight_segment_is_one_line_and_single_bar_draws_nothing | 一条直线只有首尾两个端点；单根 K 线没有折线 |
| test_chart_frame_appends_indicators_and_segment_without_mutating | 默认只补齐均线、MACD、均量和 `segment`，不含 CCI。`indicators="all"` 才带上全部指标列。输入表不被改写。样例斜率仍是 `[1,1,1,-1,-1,-1,-1]` |
| test_existing_indicator_columns_are_kept | 已有的 `ma5`、`macd_dif`、`segment` 保持输入值。缺的 `ma10`、`macd_dea` 仍会算出来 |
| test_draw_chart_panels_candles_and_segment_line | 默认三块副图：K 线、成交量、MACD。阳线红边空心，阴线青色实心。橙色「分段」折线等于 `segment_vertices`。MA5、DIF 等于对应列 |
| test_predicted_slopes_scatter_at_the_matching_eob | 预测斜率是 K 线正下方的折线，经过对应 eob 的序号。纵轴标注最大值 40、最小值 -30 和 0。40 和 -30 为黑色虚线，0 为红色虚线。斜率全部大于 0 时不画最小值，纵轴只留 0 和最大值。斜率全部小于 0 时不画最大值，纵轴只留 0 和最小值。斜率 40 不进入价格刻度。缺 `segment`，或 eob 全部对不上时报错 |
| test_indicators_argument_selects_panels_and_rejects_unknown_names | `kdj,rsi` 按固定顺序解析；`all` 覆盖全部名字；未知名字报错。只选 KDJ 时主图仍有分段折线、没有 MA5 |
| test_fibonacci_panel_uses_a_direction_axis_instead_of_price_scale | 指定 `fib` 后，方向不画进价格刻度 |
| test_missing_column_and_empty_frame_raise | 缺指标列、空表都会报错 |
| test_plot_chart_writes_png | `plot_chart` 写出的 PNG 大于 10 KB |
| test_write_chart_default_name_and_cli | 默认文件名是 `原名_chart.png`；`python -m charts 输入.csv -o 输出.png --max-error 0.03` 能写出图片 |
| test_sample_csv_smoke | 用 `data/SHSE_600031.csv` 或 `data/history_SHSE600000.csv` 整表出图，文件大于 10 KB |

颜色用红 `#ff3232`、青 `#00a3a3`、橙 `#e69500`、底 `#ffffff` 比较，允许 matplotlib 换成 RGBA 后的微小误差。

## 样例图看什么

冒烟通过只说明这张真实日线没有画崩。打开 PNG 后可以再看三处：

1. 默认图只有 K 线、成交量、MACD 三块，主图上有橙色分段折线。
2. K 线副图上的橙色折线是否贴着收盘价的转折端点，而不是在价格附近画成一条接近 0 的斜率线。
3. MACD 副图的柱子是否红涨青跌，DIF、DEA 是否为两条连续曲线。

对不上时，先用 `tests/test_charts.py` 里的七根收盘价 `[1,2,3,4,3,2,1]` 看折线是不是从 1 连到 4 再连回 1。这组数对上、长图对不上，优先检查 `max_error` 和复权，而不是先改颜色。
