# 股票常用技术指标及其含义

本文梳理 A 股与通用技术分析中常见的技术指标，说明其含义与常见用法。指标仅反映价格与成交量的历史统计特征，**不构成投资建议**；实际交易需结合基本面、市场环境与风险控制。

---

## 一、趋势类指标

### 1. MA（移动平均线，Moving Average）

- **含义**：一段时间内收盘价的算术平均值，用来平滑价格波动、判断趋势方向。
- **常见参数**：MA5、MA10、MA20、MA60、MA120、MA250（分别对应约一周、两周、月、季、半年、年线）。
- **解读要点**：
  - 价格在均线上方、均线多头排列（短线在上、长线在下）→ 偏多头趋势。
  - 价格在均线下方、均线空头排列 → 偏空头趋势。
  - 金叉（短期均线上穿长期均线）常作买入参考；死叉反之。
  - 均线也可作动态支撑/压力位。

### 2. EMA（指数移动平均线，Exponential Moving Average）

- **含义**：对近期价格赋予更高权重的移动平均，对行情变化比 MA 更敏感。
- **常见用途**：作为 MACD、部分通道指标的基础；短线交易更常参考 EMA。

### 3. MACD（异同移动平均线）

- **含义**：由快线 DIF、慢线 DEA（或称 MACD 线）及柱状图构成，衡量中短期趋势与动能。
  - DIF = 短期 EMA − 长期 EMA（常用 12、26）
  - DEA = DIF 的 EMA（常用 9）
  - 柱状图 = DIF − DEA（或 2×(DIF−DEA)，软件实现略有差异）
- **解读要点**：
  - DIF 上穿 DEA（金叉）偏多；下穿偏空。
  - 柱状图由负转正、或由缩短转拉长，反映动能变化。
  - 价格创新高而 MACD 未创新高 → 顶背离（警惕回调）；反之底背离（警惕反弹）。

### 4. BOLL / 布林带（Bollinger Bands）

- **含义**：以中轨（通常为 MA20）为中心，上下轨为中轨 ± N 倍标准差（常用 2 倍），刻画价格波动区间。
- **解读要点**：
  - 价格沿上轨运行 → 强势；沿下轨运行 → 弱势。
  - 带宽收窄（挤口）→ 波动压缩，常预示变盘；带宽放大 → 波动加剧。
  - 触及上轨不一定立刻卖出，需结合趋势；突破后回踩中轨也可作参考。

### 5. SAR（抛物线转向，Parabolic SAR）

- **含义**：在价格下方或上方画出点状止损/转向参考，趋势跟随属性强。
- **解读要点**：点从价格下方翻到上方常作空头信号，反之作多头信号；震荡市易频繁翻转。

## 二、动量 / 超买超卖类指标

### 6. RSI（相对强弱指标，Relative Strength Index）

- **含义**：衡量一段时间内涨跌幅度的相对强弱，常用周期 6、12、14、24。
- **解读要点**（以 0–100 计）：
  - 一般认为 >70（或 80）偏超买，<30（或 20）偏超卖；强势股可长期高位钝化。
  - 与价格的背离常比单纯数值更有参考价值。

### 7. KDJ（随机指标）

- **含义**：由 K、D、J 三条线组成，反映收盘价在近期高低区间中的相对位置，对短线较敏感。
- **解读要点**：
  - K 上穿 D 为金叉，下穿为死叉。
  - J 值过高（如 >100）或过低（如 <0）提示极端超买/超卖。
  - 震荡市较有效，单边趋势中易钝化、假信号增多。

### 8. CCI（顺势指标，Commodity Channel Index）

- **含义**：衡量价格偏离统计均值的程度，常用于判断是否进入超买/超卖或趋势加速区。
- **解读要点**：
  - 常用 ±100：高于 +100 偏强/超买区，低于 −100 偏弱/超卖区。
  - 从超卖区回升、或从超买区回落，可作转折参考。

### 9. WR / 威廉指标（Williams %R）

- **含义**：衡量收盘价在近期高低点区间中的位置，与随机指标思想相近，通常以负值表示（如 −20 至 −80）。
- **解读要点**：接近 0 一侧偏超买，接近 −100 一侧偏超卖。

### 10. ROC（变动率，Rate of Change）

- **含义**：当前价格相对 N 日前价格的涨跌幅百分比，直接刻画动量强弱。
- **解读要点**：ROC 上穿零轴偏多动能增强；下穿偏空。也可观察与价格的背离。

### 11. MOM（动量指标，Momentum）

- **含义**：当前价与 N 日前价格之差（或比值），反映涨跌速度。
- **解读要点**：与 ROC 类似，用于判断动能是否衰减或加速。

## 三、成交量与资金类指标

### 12. VOL / 成交量

- **含义**：一定时间内成交的股数或手数，是确认趋势真伪的重要辅助。
- **解读要点**：
  - 价涨量增、价跌量缩 → 多头较健康；价涨量缩需警惕后继乏力。
  - 放量突破关键位更可信；无量上涨或无量下跌需谨慎解读。
  - 天量之后常伴随短期情绪高潮，未必立即见顶/见底，但波动往往加大。

### 13. OBV（能量潮，On Balance Volume）

- **含义**：按涨跌日把成交量累加或累减，用“量能累积”验证价格趋势。
- **解读要点**：价格创新高而 OBV 未创新高 → 量价背离，上涨动能可能不足；反之亦然。

### 14. VWAP（成交量加权平均价）

- **含义**：按成交量加权的平均成交价格，机构与日内交易常用作成本参考。
- **解读要点**：价格在 VWAP 上方偏强，下方偏弱；常作日内回踩/反弹参考线。

### 15. MFI（资金流量指标，Money Flow Index）

- **含义**：结合价格与成交量的“成交金额版 RSI”，反映资金流入流出强度。
- **解读要点**：高位（如 >80）偏超买，低位（如 <20）偏超卖；也可看背离。

## 四、波动率与通道类指标

### 16. ATR（真实波动幅度均值，Average True Range）

- **含义**：衡量价格波动幅度大小，不指示方向，只反映“波动有多大”。
- **常见用途**：设置止损距离、仓位管理、判断行情是否进入高波动阶段。

### 17. 通道 / 轨道类（如 Donchian、恩维lope）

- **含义**：以近期最高价、最低价或均线偏移构成上下通道。
- **解读要点**：突破上轨常作趋势跟踪买入参考，跌破下轨作卖出参考（海龟等策略常用唐奇安通道）。

## 五、其他常用指标

### 18. BIAS（乖离率）

- **含义**：价格相对某条均线的偏离百分比。
- **解读要点**：正乖离过大可能回调，负乖离过大可能反弹；强趋势中阈值需放宽。

### 19. PSY（心理线）

- **含义**：统计 N 日内上涨天数占比，反映市场情绪冷热。
- **解读要点**：过高偏乐观过热，过低偏悲观；适合作为情绪辅助，不宜单独决策。

### 20. DMI / ADX（趋向指标）

- **含义**：
  - +DI / −DI：多空力量对比。
  - ADX：趋势强度（不区分多空方向）。
- **解读要点**：ADX 上升且处于较高水平 → 趋势行情；ADX 低位 → 震荡市，趋势策略易失效。+DI 上穿 −DI 偏多，反之偏空。

### 21. 斐波那契回调 / 扩展（Fibonacci）

- **含义**：用斐波那契比例（如 0.382、0.5、0.618 等）划分回调与目标位。
- **解读要点**：常作潜在支撑/压力参考，并非精确买卖点，需与其他信号共振。

### 22. 枢轴点（Pivot Points）

- **含义**：根据前一交易日（或周期）高低收计算支撑、压力与中枢价。
- **解读要点**：短线交易者常用来预判日内关键价位。

## 六、使用建议（简要）

| 场景 | 可优先关注 |
|------|------------|
| 判断大趋势 | MA/EMA、MACD、ADX |
| 找超买超卖 | RSI、KDJ、CCI、WR |
| 确认突破真伪 | 成交量、OBV、ATR |
| 波动与止损 | ATR、布林带 |
| 短线情绪 | KDJ、PSY、成交量 |

**原则简述**：

1. **多周期验证**：日线定方向，分钟/小时线找进出场。
2. **趋势市与震荡市分开看**：趋势跟踪指标在震荡中易亏损；超买超卖指标在单边市易钝化。
3. **量价结合**：价格信号最好有成交量或资金类指标佐证。
4. **背离是重要线索**：价格与 MACD/RSI/OBV 等背离，常提示动能转折，但仍需等待确认。
5. **风控优先**：任何指标组合都不能消除亏损可能，仓位与止损比“完美信号”更重要。

## 附录：名词速查

| 术语 | 含义 |
|------|------|
| 金叉 | 短期指标线上穿长期指标线，常作偏多信号 |
| 死叉 | 短期指标线下穿长期指标线，常作偏空信号 |
| 背离 | 价格创新高/新低，指标未同步，暗示动能减弱 |
| 钝化 | 强趋势中指标长期停在超买/超卖区，信号失效 |
| 支撑 / 压力 | 价格易获买盘托底 / 遇卖盘受阻的区域 |
