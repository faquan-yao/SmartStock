# 分段斜率预测使用说明

本模块用一个手写的多层感知机，根据行情表里除 `segment` 以外的列，拟合 `segment` 这一列。`segment` 是 `segment` 包算出的当前段斜率。拟合结果只描述这条斜率，不构成投资建议。

计算入口在 `forecast` 包。网络只用项目里已有的 numpy 做前向计算和反向传播，不依赖 PyTorch 或 TensorFlow。策略脚本 `main.py` 不参与训练，也不需要先登录掘金。

## 原理

一张像 `data/SHSE_600016.csv` 这样的表，每一行是一根日 K。除最后一列 `segment` 外，其余列都是输入，包括代码、时间、开高低收、成交量、成交额和已经算好的技术指标。`segment` 是要拟合的输出。

模型是全连接网络，默认两层隐藏层，宽度 32 和 16：

1. 取最近 `window` 根 K 线（含当根），把它们的特征按时间从早到晚拉直成一个向量。默认窗口是 5。
2. 每一层先做线性变换 `z = xW + b`。隐藏层再经过 ReLU，负数变成 0，正数保持原值。最后一层不再经过 ReLU，直接输出一个实数，也就是预测斜率。
3. 损失是预测值和 `segment` 的均方误差。参数用 Adam 更新，动量系数 0.9 和 0.999。权重用 He 初始化。
4. 训练前，数值特征里的空值用训练集该列的中位数填上。窗口向量再按训练集做标准化，标准差为 0 的维度除以 1，避免常数列把网络撑爆。
5. 样本按时间排列。末尾 `val_ratio`（默认 0.2）只用来记录损失，不参与更新。训练批次内部会打乱，时间切分本身不打乱。

文本列（例如 `symbol`）在训练集里按出现顺序编成 0、1、2。预测时没见过的文本先空着，再填训练集中位数。`eob` 换成距离训练集最早时间的天数。这两列因此和其他指标一样进入网络。单只股票的代码是常数，标准化之后为 0，对输出没有贡献。

窗口的前 `window - 1` 根 K 线凑不齐历史，不产生预测。输出表从第 `window` 根开始，每行对应当根的预测斜率。

样本只有几百行时，默认的两层网络用来拟合这张表。隐藏层再加宽、再加多，更容易把训练段背下来，验证段反而不稳。

## 输入数据

读入一张表。训练时必须有 `segment`。预测时可以没有这一列，但训练用过的其他列都要在。

`data/SHSE_600016.csv` 就是这种表：250 行日线，含代码、行情、技术指标和 `segment`。

- 有 `eob` 时，先按时间从早到晚排列。窗口按排好后的行来数，一行一根 K 线。
- 原始表不会被改写。
- 预测值保留完整小数，不按行情软件的显示位数四舍五入。

## 在代码里训练和预测

在项目根目录 `SmartStock` 下执行。

```python
from forecast import predict_segment, train_segment_model
import pandas as pd

history = pd.read_csv("data/SHSE_600016.csv")
model = train_segment_model(history)
predicted = predict_segment(history, model)
model.save("data/SHSE_600016_segment_model.npz")
```

`train_segment_model` 返回网络。`predict_segment` 在有 `eob` 时返回 `eob` 和 `segment`，没有 `eob` 时返回 `row` 和 `segment`。这里的 `segment` 是网络输出，不是 `linear_segment` 再算一遍的结果。

常用参数：

| 参数 | 默认 | 含义 |
|------|------|------|
| window | 5 | 含当根在内的 K 线根数 |
| hidden | (32, 16) | 各隐藏层宽度，正整数元组 |
| epochs | 300 | 训练轮数 |
| learning_rate | 0.01 | Adam 学习率 |
| batch_size | 32 | 每一批的样本数 |
| val_ratio | 0.2 | 末尾验证集比例，0 表示全部用于训练 |
| seed | 7 | 初始化和批次打乱的随机种子 |

可用样本少于 5 个时，验证集比例即使不是 0，也全部用于训练。

把参数存成文件、或从文件再预测：

```python
from forecast import load_segment_model, write_model, write_predictions

write_model("data/SHSE_600016.csv")
write_predictions("data/SHSE_600016.csv", "data/SHSE_600016_segment_model.npz")
model = load_segment_model("data/SHSE_600016_segment_model.npz")
```

`load_segment_model` 只恢复预测要用的权重、填补值和标准化参数。Adam 的中间状态不保存，读回来的网络用于预测。

## 命令行

```text
python -m forecast train data/SHSE_600016.csv -o data/SHSE_600016_segment_model.npz
python -m forecast train data/SHSE_600016.csv --window 8 --hidden 32,16 --epochs 300
python -m forecast predict data/SHSE_600016.csv --model data/SHSE_600016_segment_model.npz -o data/SHSE_600016_segment_pred.csv
```

省略 `-o` 时，训练写出 `原名_segment_model.npz`，预测写出 `原名_segment_pred.csv`，都和输入放在同一目录。已有同名文件会被覆盖。

## 输出列

`predict_segment` 返回一张新表，一行是一根能够凑齐窗口的 K 线。前 `window - 1` 根没有预测，所以行数是输入行数减去窗口再加 1。表里只有两列：用来认出是哪一根 K 线的 `eob` 或 `row`，以及这一根上的预测斜率 `segment`。

| 列名 | 何时出现 | 含义 |
|------|----------|------|
| eob | 输入里有 `eob` | 这根 K 线的结束时间，取自排序后的原表，不是网络算出来的 |
| row | 输入里没有 `eob` | 这根 K 线在按时间排好后的表中的行号，从 0 起算。窗口为 5 时，第一行的 `row` 是 4 |
| segment | 总是有 | 网络对这一根 K 线给出的分段斜率 |

`eob` 和 `row` 指的是窗口的最后一根，也就是“当根”。预测用到的是当根以及它前面 `window - 1` 根的特征。两列不会同时出现。

`segment` 的单位和 `linear_segment` 写出的斜率相同，是每一根 K 线的价格变化。正数表示网络认为当根所在直线向上，负数表示向下，接近 0 表示接近水平。它是网络的输出，不是把收盘价再做一次线性分段的结果，因此同一条真实直线上的预测值不必相等。数值保留完整小数。输入表里如果已经有 `segment`，返回值也不带回那一列真值。

## 边界

- 训练时缺 `segment`，或这一列有空值、非有限数值，直接报错。
- 预测时缺训练用过的列，直接报错。多出来的列会被忽略。
- `eob` 里有无法解析的时间，直接报错。
- 行数少于窗口，直接报错。
- 除 `segment` 外一列都没有，直接报错。
- `window`、`epochs`、`batch_size` 必须是大于等于 1 的整数。布尔值不算。
- `hidden` 里的每一层都要是大于等于 1 的整数。写成空元组时没有隐藏层，输出层直接接在输入上。
- `learning_rate` 必须是大于 0 的有限实数。
- `val_ratio` 必须在 0 到 1 之间，不能等于 1。
