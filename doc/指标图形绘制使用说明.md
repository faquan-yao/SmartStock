# 指标图形绘制使用说明

本模块把 K 线、选定的技术指标，以及 `segment` 分出的收盘价折线，画成一张同花顺配色的白底图。默认只画均线、成交量和 MACD。图只便于查看这些计算结果，不构成投资建议。

绘图入口在 `charts` 包。策略脚本 `main.py` 不参与绘图，也不需要先登录掘金。

## 环境

除项目已有的 pandas、numpy 外，还需要 matplotlib：

```text
python -m pip install matplotlib
```

图片直接写成 PNG，不弹出窗口。

## 输入数据

读入一张日线表，至少包含这些列：

| 列名 | 含义 |
|------|------|
| eob | K 线结束时间 |
| open | 开盘价 |
| high | 最高价 |
| low | 最低价 |
| close | 收盘价 |
| volume | 成交量 |

表头和前两行可以是这样。数字只说明格式，已经算好的指标列可以继续往后排：

```csv
eob,open,high,low,close,volume,ma5,macd_dif,segment
2024-01-02,10.20,10.35,10.05,10.28,1200000,10.22,0.03,0.04
2024-01-03,10.28,10.40,10.15,10.36,980000,10.25,0.04,0.04
```

这次要画的指标里，输入表已经有的列直接用来画，不再重算。某个指标只缺一部分列时，只补算缺的列，已有列保持原值。`segment` 也一样：输入里已有就直接画分段折线，没有才按收盘价现算。上面示例里的 `ma5`、`macd_dif`、`segment` 会原样保留。

- 有 `eob` 时，按时间从早到晚排列。横轴是交易日序号，不留周末空档，和行情软件的 K 线轴一致。
- 有 `symbol` 且全表只有一个代码时，标题使用该代码。
- 原始表不会被改写。

分段折线在输入没有 `segment` 时，使用默认最大相对误差 `0.03`，也可以单独传入 `max_error`。输入里已经有 `segment` 时，这个参数不再生效。

## 在代码里绘图

在项目根目录 `SmartStock` 下执行。

```python
from charts import plot_chart
import pandas as pd

history = pd.read_csv("history.csv")
plot_chart(history, "history_chart.png")          # 均线、成交量、MACD、分段折线
plot_chart(history, "loose_chart.png", max_error=0.08)
plot_chart(history, "kdj.png", indicators=("ma", "boll", "kdj"))
plot_chart(history, "all.png", indicators="all")
```

`indicators` 可以是名字元组，也可以是逗号分隔的字符串。`None` 使用默认组合 `ma,volume,macd`。`all` 画出全部可选指标。名字顺序不影响副图顺序，图始终按下面的固定顺序排列。K 线和分段折线不在这个参数里，每次都会画。

`plot_chart` 返回图片路径。省略路径时，有股票代码就写成 `{代码}_chart.png`（代码中的点换成下划线），否则写成当前目录下的 `chart.png`。

只想先拿到计算表，或自己决定怎么画：

```python
from charts import build_chart_frame, draw_chart, segment_vertices

frame = build_chart_frame(history, indicators="kdj,rsi")
xs, ys = segment_vertices(frame["close"], frame["segment"])
figure = draw_chart(frame, title="浦发银行", indicators="kdj,rsi")
figure.savefig("chart.png", dpi=120, facecolor=figure.get_facecolor())
```

`segment_vertices` 把斜率还原成折线端点：横轴是 K 线序号，纵轴是两端的收盘价。两段共用的那根 K 线只出现一次，折线在这里拐弯。

预测斜率可以叠到同一张图上。`predictions` 使用 `predict_segment` 的返回表，至少含 `eob` 和 `segment`：

```python
plot_chart(history, "pred.png", predictions=predicted)
```

有预测结果时，K 线正下方多一块「预测斜率」折线图，横轴与上面的 K 线对齐。纵轴标注这组斜率的最大值、最小值和 0。最大值和最小值是黑色虚线，0 是红色虚线。最小值大于 0 时不画最小值，纵轴只留最大值和 0。最大值小于 0 时不画最大值，纵轴只留最小值和 0。全部副图的纵坐标都在左侧。窗口开头没有预测的 K 线不连进折线。预测表里对不上当前图的 `eob` 会被跳过；一个都对不上则报错。

## 命令行

```text
python -m charts history.csv -o history_chart.png
python -m charts history.csv --max-error 0.08
python -m charts history.csv --indicators ma,boll,kdj
python -m charts history.csv --indicators all
```

省略 `-o` 时，输出文件名为原文件名加上 `_chart.png`，和输入放在同一目录。已有同名文件会被覆盖。

## 图怎么排

整张图是白底，纵坐标都在左侧。阳线红边空心，阴线青色实心。均线依次是深灰、金、紫、绿、蓝、灰。橙色粗线是分段折线，画在 K 线之上。传入 `predictions` 时，K 线下面单独加一块预测斜率折线。横轴与 K 线的交易日对齐。纵轴标注这组斜率的最大值、最小值和 0：最大值和最小值为黑色虚线，0 为红色虚线。最小值大于 0 时不画最小值，最大值小于 0 时不画最大值。

默认从上到下只有三块：K 线（含均线和分段折线）、成交量、MACD。

可选指标如下。写在 `indicators` 里才会出现。叠在 K 线上的指标不另开副图。

| 参数名 | 画在哪里 | 内容 |
|--------|----------|------|
| ma | K 线 | MA5/10/20/60/120/250，默认开启 |
| ema | K 线 | EMA12/26 |
| boll | K 线 | 布林带 |
| sar | K 线 | SAR，多头红点、空头青点 |
| vwap | K 线 | VWAP |
| donchian | K 线 | 唐奇安通道 |
| envelope | K 线 | 轨道线 |
| volume | 副图 | 红涨青跌的量柱，以及 VOL5/10/20，默认开启 |
| macd | 副图 | DIF、DEA 和 MACD 柱，默认开启 |
| kdj | 副图 | K、D、J，参考线 20、50、80 |
| rsi | 副图 | RSI6/12/14/24，参考线 30、70 |
| cci | 副图 | 参考线 ±100 |
| wr | 副图 | WR6/10，参考线 -20、-80 |
| roc | 副图 | 参考线 0 |
| mom | 副图 | 参考线 0 |
| bias | 副图 | BIAS6/12/24，参考线 0 |
| mfi | 副图 | 参考线 20、80 |
| psy | 副图 | 参考线 25、75 |
| dmi | 副图 | +DI、-DI、ADX |
| obv | 副图 | 能量潮 |
| atr | 副图 | 真实波幅均值 |
| fib | 副图 | 收盘价和各回撤、扩展位。方向 ±1 使用左侧刻度。方向切换或价位单日跳变超过收盘价的 8% 时，该线断开 |
| pivot | 副图 | 收盘价和 PP、R1–R3、S1–S3 |

周期不够而整列都是空值时，那条线不画，图例里也不出现。SAR 的多空不用 `sar_trend` 这条 ±1 序列去占价格轴，而是把多头点画成红点、空头点画成青点。

折线不是把 `segment` 斜率直接当成价格。斜率只用来找出每一段的端点，图上连接的是这些端点的收盘价。

## 边界

- 缺 K 线所需列，或选定指标的列没有先算好就调用 `draw_chart`，直接报错。
- `indicators` 里出现未知名字，直接报错。空名单也会报错。
- 空表没有 K 线，直接报错。
- 只有一根 K 线时可以画 K 线，分段折线不画。
- `max_error` 的约束与 `segment` 相同，必须是大于等于 0 的有限实数。
